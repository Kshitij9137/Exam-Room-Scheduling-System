# Source Manifest

All student, course, exam, room, invigilator, enrollment, and accommodation
records generated by this project are synthetic. The generator does not download
or use external datasets, APIs, client data, or real personal information.

## Provenance

| Item | Value |
|---|---|
| Generator package | `generator/` (`config.py`, `master_data.py`, `enrollments.py`) |
| Default deterministic seed | `20261022` |
| Starter scale | 200 students, 30 courses, 20 exams, 15 rooms, 25 invigilators |
| Full scale | 5,000 students, 300 courses, 300 exams, 100 rooms, 200 invigilators |
| External datasets or APIs | None |
| Generated email addresses | `stu######@university.example`, `inv######@university.example` |
| Generated names | Deterministic labels such as `Student 00001` and `Invigilator 00001` |

Generated data is reproducible for a fixed seed and scale. The project creates
deterministic identifiers and synthetic contact details; generated records
should not be interpreted as real people or institutions.

## Repository data and credentials

- The tracked source data is generated locally by `generator/`. Runtime
  scheduling and validation do not fetch third-party data.
- Data exports under `data/exports/` and the local SQLite database are
  development outputs and should not be committed.
- The default `SECRET_KEY` in `config/settings.py` is explicitly a development
  placeholder. Deployments must set `DJANGO_SECRET_KEY` and disable debug mode.
- If real or externally sourced data is added later, update this manifest,
  document its license and transformation history, and verify permission to
  use and redistribute it.

## Reproducibility

Run `python manage.py verify_reproducibility --seed 20261022 --scale starter`
on a database without scheduler event history to regenerate and compare
canonical master-data snapshots. The command rolls back its generated database
rows and writes a local report to `data/reproducibility_report.json`.
See [`docs/reproducibility_report.txt`](docs/reproducibility_report.txt) for
the recorded full-scale result.
